Kite Passport status
      
Built and tested with the Kite Passport CLI (kpass 6.13.2): a spending session was created and approved with a passkey (0.001 per payment, 0.01 total, 3 hours). Paying this host was refused by Kite with payment_target_forbidden / host_not_in_executable_catalog: Passport only pays hosts in Kite's service catalog. Commands used:

      
kpass session create --separate --task-summary "…" --max-amount-per-tx 0.001 --max-total-amount 0.01 --assets PIEUSD --ttl 3h
kpass session status --request-id <id> --wait
kpass session execute --url <tick url> --method GET --headers '{"pawlr-conditions-hash":"…"}' --idempotency-key <key>
